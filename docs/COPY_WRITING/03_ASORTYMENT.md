## Kategoria 1: Części eksploatacyjne

### Nagłówek karty
```
Części eksploatacyjne
```

### Ikona sugerowana
`🔧` lub ikona klucza / zębatki

### Opis
```
Filtry oleju, powietrza, kabinowe i paliwa. Klocki i tarcze
hamulcowe. Amortyzatory, wahacze, sworznie. Elementy układu
kierowniczego. Paski rozrządu i klinowe.

Wszystko od sprawdzonych producentów z rynku niezależnego (IAM)
– doradzimy zamiennik, który spełni swoją rolę bez przepłacania.
```

### Podpunkt / Slogan karty
```
Regularna wymiana = spokojne kilometry.
```

---

## Kategoria 2: Oleje silnikowe i przekładniowe

### Nagłówek karty
```
Oleje silnikowe
```

### Ikona sugerowana
`🛢️` lub ikona kropli oleju

### Opis
```
Syntetyczne, półsyntetyczne, mineralne – w lepkościach
dopasowanych do Twojego silnika. Prowadzimy oleje renomowanych
marek w pojemnościach od 1L do 5L.

Nie wiesz, który olej wybrać? Podaj model auta – dobierzemy
właściwą specyfikację.
```

### Podpunkt / Slogan karty
```
Właściwy olej to dłuższe życie silnika.
```

---

## Kategoria 3: Chemia samochodowa i płyny eksploatacyjne

### Nagłówek karty
```
Chemia i płyny
```

### Ikona sugerowana
`🧪` lub ikona butelki

### Opis
```
Płyny chłodnicze, hamulcowe, do spryskiwaczy. Środki do
pielęgnacji lakieru, wnętrza i silnika. Preparaty antykorozyjne,
smary, odrdzewianie i kleje techniczne.

Od codziennej eksploatacji po sezonowe przygotowanie auta –
mamy chemię na każdą okazję.
```

### Podpunkt / Slogan karty
```
Zadbane auto to bezpieczne auto.
```

## Kategoria 4: Detailing i kosmetyki samochodowe

### Nagłówek karty
```
Detailing i pielęgnacja
```

### Ikona sugerowana
`✨` lub ikona polerowania

### Opis
```
Szampony, woski, glinki, polerki. Środki do czyszczenia
tapicerki, plastików i szyb. Mikrofibry i akcesoria do
detailingu.

Twoje auto zasługuje na to, żeby wyglądać jak nowe –
niezależnie od tego, ile ma na liczniku.
```

### Podpunkt / Slogan karty
```
Efekt „prosto z salonu" w Twoim garażu.
```

## Kategoria 5: Akcesoria motoryzacyjne

### Nagłówek karty
```
Akcesoria
```

### Ikona sugerowana
`🚗` lub ikona auta

### Opis
```
Dywaniki dedykowane i uniwersalne. Pióra wycieraczek.
Żarówki samochodowe i LED. Apteczki, trójkąty, gaśnice.
Adaptery, ładowarki, baterie. Podstawowe narzędzia warsztatowe.

Drobiazgi, które robią różnicę – w komforcie jazdy
i bezpieczeństwie na drodze.
```

### Podpunkt / Slogan karty
```
Małe rzeczy. Duże znaczenie.
```

### Nagłówek karty

```
Zawieszenie i hamulce
```

### Ikona sugerowana
`🛞` lub ikona amortyzatora

```
Amortyzatory, sprężyny, wahacze, łączniki stabilizatora.
```

```
Oświetlenie i elektryka
```
