## Q&A

### Q1
**Pytanie:**
```
Czy mogę zamówić część, której nie macie na stanie?
```

**Odpowiedź:**
```
Tak. Współpracujemy z wiodącymi hurtowniami motoryzacyjnymi
w Polsce. Większość zamówionych części dostarczamy do sklepu
jeszcze tego samego dnia – często w ciągu kilku godzin.
```

---

### Q2
**Pytanie:**
```
Jak dobrać właściwą część do mojego samochodu?
```

**Odpowiedź:**
```
Wystarczy, że podasz markę, model, rocznik i pojemność silnika.
Jeśli masz numer VIN – jeszcze lepiej. Dobierzemy właściwy
zamiennik na miejscu lub telefonicznie.
```

---

### Q3
**Pytanie:**
```
Czy sprzedajecie oleje silnikowe? Jak wybrać odpowiedni?
```

**Odpowiedź:**
```
Tak – mamy oleje syntetyczne, półsyntetyczne i mineralne
w różnych lepkościach. Jeśli nie wiesz, który olej pasuje
do Twojego silnika, podaj model auta – doradzimy właściwą
specyfikację zgodną z zaleceniami producenta.
```

### Q4
**Pytanie:**
```
Jakie formy płatności akceptujecie?
```

**Odpowiedź:**
```
Płatność gotówką oraz kartą. Dla stałych klientów
biznesowych wystawiamy faktury VAT.
```
